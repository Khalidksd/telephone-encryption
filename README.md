Telephone Encryption System

About This Project:-

I created this project while learning Python. I wanted to make a simple encryption program using a telephone keypad and practice using if/elif statements and loops.

The program can encrypt a message into numbers and also decrypt the numbers back into a message.
How It Works

I used the letters on a traditional telephone keypad.

For example:

A = 2
B = 22
C = 222
H = 44
E = 33
L = 555
O = 666

So the word:

HELLO

can be converted to:

44-33-555-555-666

The program can then use those numbers to get the message back.

Running the Program

First, clone the repository:

git clone https://github.com/Khalidksd/telephone-encryption.git

Then go into the project folder:

cd telephone-encryption

Run the program:

python3 telephone_encryption_ifelif.py
