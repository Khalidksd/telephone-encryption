📞 Telephone Encryption Using Python


A simple Python project I created while learning about Python, encryption, Linux, Git, and GitHub.

The program allows a telephone number to be encrypted and then decrypted back to its original value.
🔐 What This Project Does

The basic process is:

Telephone Number
       ↓
   Encryption
       ↓
Encrypted Number
       ↓
   Decryption
       ↓
Original Number

The project is designed to be simple enough for beginners who want to experiment with basic encryption concepts.

🚀 Getting Started
1. Clone the repository

Open your terminal and run:

git clone git@github.com:Khalidksd/telephone-encryption.git

2. Enter the project folder

cd telephone-encryption

3. Check Python

Make sure Python 3 is installed:

python3 --version

You should see something similar to:

Python 3.x.x

4. Run the program

python3 telephone_encryption.py

Follow the instructions shown in the terminal.
🧑‍💻 Beginner Example

You can use a test telephone number to try the program.

For example:

+234 7018112309

The program will encrypt the number and provide an encrypted result.

The encrypted result can then be decrypted to recover the original number.
